# Contributing to CodeShield AI

We welcome contributions from developers, security researchers, and security practitioners. Here is how you can help:

## Code Contributions
1. Fork the repository and create your branch from `main`.
2. Install development dependencies.
3. Keep changes minimal and focused.
4. Ensure code linting and formatting pass successfully:
   - Run `flake8` and `black --check .`
   - Run `mypy .`
5. Submit a detailed Pull Request.

## Security Disclosures
Please do NOT open public issues for zero-day vulnerabilities. Check [SECURITY.md](file:///d:/AgenticAI/CodeShield-AI/SECURITY.md) to report security flaws.
