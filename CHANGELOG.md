# Changelog

All notable changes to **CodeShield AI** will be documented in this file.

## [1.0.0] - 2026-07-01
### Added

- First public release of CodeShield AI.
- Multi-source inputs (GitHub, GitLab, Local Folder, ZIP Upload).
- Dynamic Theme options (Dark, Light, System) and Custom Scrollbars.
- AI chunk grouping to reduce LLM api 429 warnings.
- Interactive side-by-side code viewer modal highlighting lines.
- SARIF, HTML, CSV, PDF, Markdown reports download.
- POST cancel scan active task endpoint.
